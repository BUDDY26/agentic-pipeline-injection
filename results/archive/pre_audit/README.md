# Pre-Audit Results (Superseded)

methodology audit. They are retained for provenance only and do not reflect
the corrected experimental record.

- `taxonomy.csv` — pre-audit aggregate taxonomy; values do not match the
  corrected record.
- `charts/` — pre-audit visualization PNGs.

The canonical, post-audit results live in:

- `results/validation/multi_run_results.csv` — per-run and aggregate metrics
- `results/validation/baseline_stability.csv` — baseline control verification
- `results/validation/validation_summary.md` — narrative summary and limitations
- `results/figures/` — publication-quality figures (A–E)
